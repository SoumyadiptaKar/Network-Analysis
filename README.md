# Network Analysis

A comprehensive study repository for learning network analysis and graph theory using NetworkX. This repository contains Jupyter notebooks, Python examples, and practical demonstrations of graph creation, visualization, and analysis.

## 📚 Contents

- **Notebooks**: Interactive Jupyter notebooks with detailed explanations
  - `01_intro_to_graphs.ipynb` - Introduction to creating different types of graphs
  - `02_graph_analysis.ipynb` - Graph analysis techniques and centrality measures
  
- **Examples**: Python scripts demonstrating graph operations
  - `basic_graphs.py` - Creating and visualizing basic graphs
  - `graph_analysis.py` - Analyzing networks with various metrics

## 🚀 Getting Started

### Prerequisites

- Python 3.8 or higher
- pip package manager

### Installation

1. Clone the repository:
```bash
git clone https://github.com/SoumyadiptaKar/Network-Analysis.git
cd Network-Analysis
```

2. Install required packages:
```bash
pip install -r requirements.txt
```

### Running Notebooks

Start Jupyter Notebook:
```bash
jupyter notebook
```

Navigate to the `notebooks/` directory and open any notebook to start learning.

### Running Examples

Execute example scripts:
```bash
python examples/basic_graphs.py
python examples/graph_analysis.py
```

## 📖 Topics Covered

### Graph Creation
- Undirected graphs
- Directed graphs
- Weighted graphs
- Common graph types (complete, path, cycle, star)
- Random graph models (Erdős-Rényi, Barabási-Albert, Watts-Strogatz)

### Graph Analysis
- Basic properties (degree, density, connectivity)
- Centrality measures:
  - Degree centrality
  - Betweenness centrality
  - Closeness centrality
  - Eigenvector centrality
- Clustering coefficient
- Shortest paths and path lengths
- Community detection
- Degree distribution

### Visualization
- Spring layout and other layout algorithms
- Node sizing and coloring by attributes
- Edge weight visualization
- Community visualization
